# Changelog

All notable changes to Kibo Climb are documented in this file.

## [1.0.0-mvp] - 2026-09-22

### Minimum Viable Product (MVP) Release
The official initial release of Kibo Climb — a fun daily learning climb across Math, Words, Geography, and Coding.

#### Features
- **Multi-Subject Learning Engine:**
  - Fast-paced math challenges with adaptive Elo rating adjustments.
  - Vocabulary & spelling mechanics with audio hints and sentence context.
  - Interactive world & US geography map challenges using D3/TopoJSON.
  - Logic & coding foundations (loops, branches, sequences).
- **Streak & Mastery Progression:**
  - Daily streaks, streak freezes, Spark reward currency, and milestone badges.
  - Adaptive level tiers with climb progression towards Mount Kibo summit.
- **Multi-Profile & Family Support:**
  - Multiple learner profiles per parent account.
  - Parental pin gate, dashboard oversight, and weekly progress email reports.
- **Audio Experience:**
  - High-performance, low-latency sound effects (SFX) with Web Audio API.
  - Centralized single-stream background music (BGM) across Lobby, Workshop, and Active Climb.
- **PWA & Offline First:**
  - Full Progressive Web App (PWA) offline support via Workbox.
  - Web Push notifications via OneSignal with dedicated background worker integration.
  - Cross-platform support (Web, iOS/Android via Capacitor).
